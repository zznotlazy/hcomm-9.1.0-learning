## Description

Initializes HCCL based on rootInfo and creates an HCCL communicator with specific configurations.

This API supports concurrent call by multiple threads within the same process, but only in the single-device single-thread scenario. In the single-device multi-thread scenario, concurrent call is not supported.

As shown in the following figure, concurrent call of step0 and step1 is not supported. step1 must be executed serially after step0 completes.

![Concurrent call not supported](figures/commit_rootinfo_config.png)

## Function Prototype

```c
HcclResult HcclCommInitRootInfoConfig(uint32_t nRanks, const HcclRootInfo *rootInfo, uint32_t rank, const HcclCommConfig *config, HcclComm *comm)
```

## Parameters

| Parameter | Input/Output | Description |
| --- | --- | --- |
| nRanks | Input | Number of ranks in the cluster. |
| rootInfo | Input | Root rank information, mainly including the IP address and ID of the root rank. It is generated by the [HcclGetRootInfo](HcclGetRootInfo.md) API. |
| rank | Input | Rank ID of the current rank. |
| config | Input | Communicator configuration, including the buffer size, deterministic computation switch, communicator name, communication operator expansion mode, and other information. The configuration parameters must be within the valid value range. For details about the meanings and priorities of the parameters in HcclCommConfig, see the definition of [HcclCommConfig](./data_type_definition/HcclCommConfig.md).<br>Note: The config passed in must be initialized by calling [HcclCommConfigInit](HcclCommConfigInit.md) first. |
| comm | Output | Pointer to the initialized communicator.<br>For the definition of the HcclComm type, see [HcclComm](./data_type_definition/HcclComm.md). |

## Return Value

[HcclResult](./data_type_definition/HcclResult.md): The API returns HCCL_SUCCESS on success, and other values on failure.

## Constraints

The nRanks, rootInfo, and config of all ranks in the same communicator must be the same.

## Example

```c
uint32_t rankSize = 8;
uint32_t deviceId = 0;
// Generate the rank identifier information of the root node.
HcclRootInfo rootInfo;
HcclGetRootInfo(&rootInfo);

// Create and initialize the communicator configuration.
HcclCommConfig config;
HcclCommConfigInit(&config);
// Modify the communicator configuration as needed.
config.hcclBufferSize = 1024;  // Size of the buffer for shared data, in MB. The value must be greater than or equal to 1. The default value is 200.
config.hcclDeterministic = 1;  // Enable deterministic computation for reduction-type communication operators. The default value is 0, which disables deterministic computation.
std::strcpy(config.hcclCommName, "comm_1");
// Initialize the collective communicator.
HcclComm hcclComm;
HCCLCHECK(HcclCommInitRootInfoConfig(rankSize, &rootInfo, deviceId, &config, &hcclComm));

// Destroy the communicator.
HcclCommDestroy(hcclComm);
```
